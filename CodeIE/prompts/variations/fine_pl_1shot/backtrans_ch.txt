**Text:**

**Named entities in the text:**

**Annotation guidelines:**

Extract named entities based on the following categories:
* Person
* Organization
* Location
* Event
* Date
* Time
* Product
* Art work

---

### Example 1

```python
def nlp_task(input_text):
    return {
        'text': input_text,
        'named_entities': input_text
    }
```

**Text:**

```python
input_text = "He contributed to the program 'Men's Show'."
```

**Named entities:**

```python
return [
    nlp_task(input_text),
    {"text": "Men's Show", "type": "art-broadcastprogram"}
]
```
